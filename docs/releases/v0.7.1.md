# Synthe v0.7.1

The first public release. Your coding agent works in its own macOS account and holds no GitHub
credential. When it wants to push, a separate broker shows you the exact commit. You approve it with
Touch ID or your passphrase. The broker checks the commit again and pushes exactly that commit. Then it
writes a signed, hash-chained receipt, which anyone can check with `synthe-verify`.

## Install

```bash
curl -sSL https://synthe.live/install | bash
```

The installer clones this tag and checks that it's on the tagged commit. It installs nothing until
those checks pass. To pin the exact commit as well:

```bash
curl -sSL https://synthe.live/install | SYNTHE_EXPECTED_COMMIT=<commit> bash
```

Then follow [QUICKSTART_OPENCLAW.md](../../QUICKSTART_OPENCLAW.md) from "prepare". `synthe-init doctor`
should report **ENFORCED**.

## What's in it

- **The commit broker.** It runs as its own user and holds the token. It re-checks the approved commit
  and pushes with compare-and-swap, so a moved branch is refused rather than overwritten. It writes a
  signed receipt for every push and every refusal.
- **Approval cards** (#14, #17). Each push is sorted as routine, review or high risk, based on its size,
  paths and deletions. High-risk pushes show the full commit and ask you to type part of it. Evidence
  that is missing or malformed counts as high risk. The agent's own description comes last.
- **Approvals bind the budget** (#10). The approval signature covers tokens, cost and time.
- **OpenClaw kit.** It sets up the barrier plugin, the MCP server and the skill. Setup and the doctor
  now cover every configured agent (#19, #22).
- **Claude Code plugin 0.6.4** (#15, #21, #23). Its hook routes publishing to the approval flow. It
  blocks `git push`, PR creation, releases, credential reads and writes to the GitHub API. Ordinary
  commands and API reads run unchanged.
- **Signed agent registry.** There's now a runbook for signing it and pinning the genesis key (#9,
  #20).
- **Red team report** (#13, #18). It covers 30 attacks and 3 controls. The broker refused 13 of them
  and wrote a receipt for each. See [docs/REDTEAM.md](../REDTEAM.md); the raw data is in
  `docs/results/`.
- **CI on every PR**, on macOS and Linux, plus the plugin tests (#12).

## Known limits

- The credential wall is the boundary. The Claude Code hook and the OpenClaw plugin are guards in
  front of it, not sandboxes.
- If a push may have landed but the remote doesn't show it, the receipt marks it unconfirmed
  (`effect_unconfirmed`). Synthe doesn't reconcile that automatically yet, and it never guesses.
- The registry is unverified until you pin a genesis key, and the macOS broker can't be pinned yet.
  See [docs/REGISTRY_GENESIS_KEY.md](../REGISTRY_GENESIS_KEY.md).
- Enforced setup is for macOS. Linux setup only works on a fresh install; there's no upgrade path yet.
